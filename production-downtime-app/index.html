Coller des arrêts depuis Excel

Collez directement l'extraction complète des arrêts (11 colonnes : seules la date début, la date fin, le code FER, le code Macc et la description sont reprises), ou bien les 5 colonnes date début, date fin, code FER, code Macc, détail. Format des dates : jj/mm/aaaa hh:mm:ss. Les lignes d'en-tête sont ignorées et les espaces superflus du détail sont supprimés.

Le diamètre de chaque arrêt vient de l'onglet Programme de laminage, selon son heure de début.

Modifier des arrêts

Retrouvez un arrêt par sa journée de production (8h à 8h) ou par une recherche, puis modifiez ses dates, codes, détail ou diamètre. Les actions et le REX de l'arrêt sont conservés.

Derniers imports

Chaque collage ou import de fichier est enregistré comme un import. En cas d'erreur de manipulation, supprimez l'import concerné : tous ses arrêts sont retirés.

Tables de correspondance des codes

Les numéros de code FER et de code Macc sont remplacés par leur nom dans les analyses et le plan d'actions. Pour mettre une table à jour, copiez ses deux colonnes (code, nom) depuis Excel, collez-les ci-dessous et remplacez la table choisie. La nouvelle table s'applique à tous les utilisateurs.

Base de données JSON

Tous les arrêts et toutes les actions sont enregistrés dans une base partagée par tous les utilisateurs de cette page. Vous pouvez l'exporter en fichier JSON (sauvegarde, archivage) ou importer un fichier JSON exporté auparavant : ses arrêts et actions sont ajoutés à la base, sans doublons.

Profils

L'application s'ouvre en lecture seule. Le bouton « Se connecter » en haut de page débloque un profil par mot de passe, pour la durée de l'onglet. Les modifications exigent en plus le niveau Éditeur dans le menu Partager.

Programme de laminage

Les diamètres laminés, avec leur date et heure de démarrage et de fin. Chaque arrêt prend le diamètre de la campagne en cours à son heure de début. Les journées de production vont de 8h à 8h.

Coller plusieurs lignes depuis Excel (diamètre, démarrage, fin)

Compte rendu journalier

1. Point sécurité

2. Qualité, environnement

3. Production

4. Frise chronologique (8h → 8h)

5. Pareto du jour

Production

Saisissez pour chaque journée de production (8h à 8h le lendemain) les tonnes produites et le temps d'ouverture. Le temps d'arrêt vient des arrêts saisis. Taux de marche = (ouverture − arrêts) ÷ ouverture. Productivité = tonnes ÷ temps d'ouverture.

Coller plusieurs jours depuis Excel (date, tonnes, temps d'ouverture)

Énergie

Une ligne par journée de production (8h à 8h le lendemain). Les ratios par tonne utilisent la production saisie dans l'onglet Production. Les objectifs se règlent dans le menu KPI - Objectifs.

Coller plusieurs jours depuis Excel (date, gaz maintien, gaz production, élec maintien, élec production)

Objectifs des indicateurs (KPI)

Pour chaque indicateur : vert si l'objectif est atteint, orange entre l'objectif et le seuil d'alerte, rouge au-delà du seuil. Au-delà de la valeur limite, la valeur est signalée « ⚠ limite ». Les couleurs s'appliquent au CR journalier et aux onglets Production et Énergie. Le % de non conformes se saisit en % (ex. 0,5).

Statistiques

Actions

Toutes les actions, toutes périodes confondues, selon les filtres diamètre, type d'arrêt et machine. Classées par délai. La saisie et la modification des actions sont réservées aux Admin ; les Utilisateurs peuvent les clôturer avec un commentaire.

REX

Tous les REX, toutes périodes confondues, selon les filtres diamètre, type d'arrêt et machine, avec leurs actions. Les Admin peuvent modifier un REX directement ici ou depuis l'onglet Saisie des actions / REX.
