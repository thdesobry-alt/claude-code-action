Coller des arrêts depuis Excel

Sélectionnez les 5 colonnes dans Excel (date début, date fin, code FER, code Macc, détail), copiez, puis collez ci-dessous. Format des dates : jj/mm/aaaa hh:mm:ss. Les lignes d'en-tête sont ignorées et les espaces autour du détail sont supprimés.

Arrêts enregistrés par diamètre

Tables de correspondance des codes

Les numéros de code FER et de code Macc sont remplacés par leur nom dans les analyses et le plan d'actions. Pour mettre une table à jour, copiez ses deux colonnes (code, nom) depuis Excel, collez-les ci-dessous et remplacez la table choisie. La nouvelle table s'applique à tous les utilisateurs.

Base de données JSON

Tous les arrêts et toutes les actions sont enregistrés dans une base partagée par tous les utilisateurs de cette page. Vous pouvez l'exporter en fichier JSON (sauvegarde, archivage) ou importer un fichier JSON exporté auparavant : ses arrêts et actions sont ajoutés à la base, sans doublons.

Profils

Le profil de chaque personne vient de son niveau d'accès à la page, réglé par le propriétaire dans le menu Partager.

Admin

Niveau Éditeur ou propriétaire.

  • Colle et supprime des arrêts
  • Choisit l'axe Machine / Type
  • Importe et exporte la base JSON
  • Analyse et renseigne les actions
Utilisateur

Niveau Contributeur.

  • Consulte les analyses Pareto
  • Renseigne type d'action, action, pilote et délai
  • Exporte la base JSON
Lecture seule

Niveau Lecteur ou Commentateur.

  • Consulte analyses et actions sans les modifier

Plan d'actions

Tous les arrêts de la période et des filtres sélectionnés. Type d'action, Action, Pilote et Délai sont enregistrés automatiquement et visibles par tous.
